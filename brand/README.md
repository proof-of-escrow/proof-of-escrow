# Brand

The mark is a padlock whose shackle is a timer. The pale track is the whole lock; the amber arc is the time still to run, which is what Proof of Escrow pays for.

| Token | Value | Use |
|---|---|---|
| Ink | `#0E1014` | background |
| Bone | `#F2EEE6` | mark body, type |
| Amber | `#F0B44C` | time remaining, used once per surface |

Type is Helvetica Neue: Medium for the name, Regular at 62% bone for the line under it.

| File | Size | For |
|---|---|---|
| `mark.svg` | any | source of the mark, transparent |
| `avatar.png` | 1000 x 1000 | organization avatar |
| `banner.png` | 1600 x 500 | README header |
| `social.png` | 1280 x 640 | repository social preview |

The `.svg` files next to each PNG are the sources; render with `rsvg-convert <file>.svg -o <file>.png`.
