# Security

Please report vulnerabilities privately through GitHub: **Security**, then **Report a vulnerability**, on this repository. Do not open a public issue.

In scope:

- Anything in [SPEC.md](SPEC.md) that lets an account earn more than its locks entitle it to, lets honest calculators disagree, or allows a payment that no report justifies.
- Bugs in the reference calculator that produce a wrong report or wrong payments.

The reference calculator holds no keys and sends nothing. Each distribution is run by its own operator or signers, who are responsible for their keys and payouts.
